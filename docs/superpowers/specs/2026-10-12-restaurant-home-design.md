# 禾间小馆餐馆首页设计（迁移前）

日期：2026-10-12

## 目标与范围

用户希望首页帮助顾客了解餐馆、查看招牌菜。实现中文品牌展示首页，兼容手机和电脑。品牌“禾间小馆”、菜品及到店信息均为可替换的示例内容，页面应明确标注示例联系方式，避免误导。

本次交付为当前工作目录内的完整前端首页。包含内容展示、页内导航及菜品类别筛选；不包含在线点餐、支付、订座后台或用户账户。

## 视觉设计

使用温暖的现代中餐馆风格：米白背景、深棕文字、朱红强调色。通过大幅美食图、舒展排版和细线分隔营造亲切而有质感的体验。标题使用具有中文阅读表现的字体回退组合，正文保持清晰。避免依赖远程字体才能呈现布局。

## 页面结构

1. 顶部导航：品牌标识、招牌菜、餐馆故事、到店信息；手机提供可访问的菜单按钮。
2. 首屏：品牌名称、简短介绍、美食主图、“探索招牌菜”页内跳转按钮。
3. 招牌菜：六道示例菜品，以图片、名称、特色描述及示例价格展示；类别为全部、招牌热菜、时令小菜。筛选在浏览器内即时完成。
4. 餐馆故事：食材选择、烹饪理念和空间氛围，搭配环境图片。
5. 到店信息：示例地址、营业时间及联系方式；将示例身份明确显示，避免使用无法履约的预订入口。
6. 页脚：品牌名称及简短说明。

## 技术与数据

使用无构建步骤的 HTML、CSS 和 JavaScript，降低空项目初始化成本。页面由静态内容和浏览器内交互组成，无服务器数据依赖。图片应提供语义化替代文本；媒体加载失败时保持尺寸与背景，避免布局坍塌。所有示例品牌、菜品和联系信息集中组织，便于后续替换。

采用语义化页面结构、清晰键盘焦点、足够色彩对比；筛选按钮暴露当前选中状态，移动导航按钮暴露展开状态。减少动态效果偏好得到尊重。

## 错误与边界

类别筛选仅切换本地菜品，无网络请求。移动菜单点击导航后关闭。页面在 JavaScript 不可用时仍能阅读全部核心内容。图片有稳定占位背景。示例联系信息不提供虚假的提交成功流程。

## 验收

- 首页呈现以上所有内容区块，中文文案完整。
- 首屏按钮和导航能跳转到相应区块。
- 菜品分类筛选正确，回到全部后恢复六道菜。
- 手机菜单能打开、关闭，并支持键盘操作。
- 桌面和手机宽度无横向溢出，图片比例稳定、文字清楚。
- 通过静态文件与 JavaScript 语法检查，并在可用的浏览器预览中检查布局和交互。

## 已确认与假设

用户已确认品牌展示用途，以及温暖现代中餐馆风格、招牌菜、餐馆故事、到店信息结构。餐馆名称和经营内容为示例；如提供真实品牌资料，可替换而无需改变页面结构。部署目标尚未指定，本设计的核心交付为可运行源码。

## Vue 3 迁移记录（2026-10-12）

当前实现已迁移为 Vue 3 + Vite，使用 Composition API 与组件化页面。原文中的无构建静态运行方式及禁用 JavaScript 仍可阅读全部内容的约定已被替代：现在通过 npm 开发和构建，部署 dist 静态文件，并在禁用 JavaScript 时显示提示。页面内容、视觉和交互目标继续保留。
